# 知行·数学建模实验室

统一的高中数学建模网页。结合课标、人教A版教材与知识图谱，依据整学期教学计划和当前学习进度，在最近发展区内设计有挑战的建模项目。每个新项目使用1个可视实验。先确定最后的综合问题，再将求解所需的中间结果拆成4～6道具体小问，每题填写公式与定量结果。

## 启动

需要Node.js22或更高版本。服务端使用内置模块，公式输入与计算组件已随源码提供，无需额外安装。

```powershell
node src/server.mjs
```

打开[本地demo](http://127.0.0.1:3000)。可用PORT环境变量更换端口。

```powershell
node --test src/tests/*.test.mjs
```

## 使用流程

1．选择服务商，输入模型名称和API密钥。连接会实际调用一次模型，成功后显示连接状态。

2．上传或填写整学期教学计划与当前进度，选择数学模块、兴趣和活动时长。探索方式可选几何、优化、概率、路线，也可以交给AI选择一种合适的方式。

3．点击“生成建模项目”。后端将课标摘要、完整紧凑知识图谱和相关教材原文定位加入请求。每个新项目包含1个实验和4～6个阶段，并给出已有知识、最多3项拓展知识、学习支架及学期衔接说明。生成结果标明实际模型、时间、耗时和请求编号。

4．按每题的具体作答项写数学表达式、计算数值并作判断。公式输入器支持点击分数、根号、上下标、三角函数和符号输入，支持角度制与弧度制代入计算。图形与滑杆用于观察和检验，前题公式及数值可在后题调用。

5．填写尝试或具体困难后请求提示，AI会收到当前状态、既有作答、学期计划、进度，以及本项目相关教材知识与前置子图。提示按观察方向、方法线索和下一步操作递进。已连接AI时，预置示例同样可以使用实时提示与反馈。

6．保存本题，可以导出JSON完整记录或Markdown专题作业。模型收到的作答同样采用Markdown数学公式块，包含公式、数值、单位及本次数值计算的代入记录。

教学计划和进度支持UTF－8编码的TXT、MD、Markdown、TeX和CSV文件。计划上限3万字，进度上限4000字；较长的进度文件需要在页面内整理。学习记录自动保存在当前浏览器，密钥不会进入本地存储或导出文件。

## 知识图谱

点击顶部“知识图谱”，或打开[知识图谱页面](http://127.0.0.1:3000/knowledge-graph.html)，可以浏览五册教材的知识依赖。页面直接读取books目录中的knowledge-graph.full.json，包含234个知识点和418条依赖边。

支持按教材筛选、按名称或章节搜索、按编号定位，以及缩放和平移。选中节点后显示学习要求、教材页码、原文定位片段和直接前置、后续知识。勾选“只看当前节点的直接依赖”可查看包含跨册知识的局部图；点击前置或后续知识可以继续浏览。

图谱可在进入建模项目前浏览。前置依赖为教材内容分析结果，完整JSON中的validation记录了有向环检查结果。修改服务端代码后，需要重新启动本地服务；更新图谱JSON后，刷新页面即可读取新内容。

## 根据模型设计渲染实验

| 实验类型 | 直观操作 | 由AI设计的内容 |
| --- | --- | --- |
| 几何探索 | 拖动点、改变长度和角度、观察图形与约束、保存对照 | 点、线段、矩形、多边形、圆和椭圆；参数范围；指标公式与约束 |
| 方案优化 | 调整设计变量与情境参数，比较目标值和约束余量 | 显式目标函数、变量范围、约束、几何可视化与观测公式 |
| 概率模拟 | 调整总体、放回规则和抽取数量，运行随机试验 | 对象类别、数量、目标事件和试验规模 |
| 路线规划 | 点击相邻节点、比较路径、检验到达条件和代价 | 地图节点、连接关系、权重、起终点与可选必经点 |

新项目采用version为2的协议，experiments数组固定为1项，所有阶段通过interaction.experimentId引用它。taskData提供需要整理的任务数据，modelingStep标明建模环节，knowledgeIds连接教材图谱，learningDesign描述学情、挑战、支架和学期衔接。已有的多实验项目仍可打开。

几何计算使用受限的数学表达式解析器，支持四则运算、乘方、三角函数等数学操作。模型输出被解释为图形和规则数据。新增可视组件需要同时更新渲染器、协议校验与集中提示词。

## 题目多样性与API作用

新项目按现实问题选择1种实验类型，自动选择时优先推荐近期较少使用的方式，并将最近项目作为变化情境、关系和策略的参考。用户指定探索方式时使用该类型。优化实验支持受限数学表达式表示的最小化或最大化函数，关键求解和方案取舍由学生完成。

后端校验知识编号与名称、最多3项拓展知识的前置依赖、每项新知识的支架，以及数据处理、模型建立、模型求解、结果分析4个必备环节。知识匹配与任务难度属于模型根据学情作出的教学判断，可在“学习起点与挑战安排”中核查。

生成、提示和反馈接口返回调用来源信息。页面分别显示“AI已连接”和“题目来源”，避免把旧示例误认为新生成内容。生成失败时显示错误，不把预置项目替换为AI结果。

API支持OpenAI、DeepSeek、通义千问及自定义OpenAI兼容Chat Completions接口。DeepSeek默认使用deepseek-flash，模型名称可编辑。密钥仅保存在本地后端会话内存，默认2小时失效，断开或重启后清除。教学资料、生成项目及解题状态会发送到用户选择的服务商。

DeepSeek返回402表示API账户余额不足，需要在[开放平台充值页面](https://platform.deepseek.com/top_up)检查余额并充值后重连；429表示请求频率或并发达到限制。状态码含义见[DeepSeek官方错误说明](https://api-docs.deepseek.com/quick_start/error_codes/)。连接验证最多输出16个token，项目生成使用正常输出容量。

DeepSeek结构化请求启用[JSON输出模式](https://api-docs.deepseek.com/guides/json_mode/)。项目生成和修复启用[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)，推理与回答合计上限为32768个token，单次请求最长等待240秒。参数配置支持固定情境量，使用min=max=value及非负步长，页面显示固定数值，目标函数可引用这些常量；优化设计变量仍需有变化范围。校验失败后自动修复1次，若仍失败，页面展示具体实验、参数或字段原因。

## 示例与旧项目

默认示例“极光号卫星通信：轨道拟合与方案设计”面向已掌握概率和标准椭圆题的学生。学生首先根据8个观测点拟合圆或椭圆，再固定参数、用4个预留点检验。随后判断卫星是否满足通信条件，计算多次发送后的成功概率，并比较达到99％成功率的两种方案。

6道题的标题为：

1．选择模型并初步拟合观测数据

2．估计椭圆参数并检验拟合结果

3．判断两个站点能否同时通信

4．计算多次发送后的成功概率

5．求满足通信要求的最小半长轴

6．比较达到99％成功率的两种方案

每道题按“已知条件—分步任务—答案要求”展示。新增符号在使用前定义，公式框与数值框说明所求的量和精度。学生使用过的方法说明、统计量、Python模板与提示会进入学习记录。第2题核对后，第3题方法说明默认收起。

本地Python实验台使用Pyodide0.28.3、Python3.13.2与NumPy2.2.5，提供可编辑分步代码、运行、停止和结果保存。依赖随源码提供，运行时从本机加载；使用Web Worker保持页面响应，单次计算超过10秒会停止。Python代码和结果可随Markdown提供给AI反馈。

工作台采用紧凑排版：宽屏将图形与参数并排展示，拟合阶段只显示a、e控件；最终挑战、任务数据和知识联系按需展开，当前题目与分层提示保留在侧栏。

运行环境与数据均可离线使用，AI提示和反馈需要连接服务。上台顺序、教师参考数值与模板填空见[演示指南](./demo-guide.md)。新版示例版本号为6，重新进入示例会载入新题组；原有记录在主动进入新项目之前保留。

version为1的拟合项目和历史多实验项目保留兼容支持。课标摘要、教材及图谱在服务启动时加载，更新这些教学依据或提示词后需要重启服务。

## 调试

任务数据表允许文本、有限数值、布尔值与null。空字符串、空白字符和null在页面显示为“—”，0正常显示，布尔值显示为“是”或“否”。单元格说明保留完整文本，总大小受模型响应上限约束。嵌套数组或对象需要改写成文本，校验错误会指出具体行列和字段路径。

运行`node src/tests/browser-harness.mjs`启动独立的固定响应测试服务。访问[测试页面](http://127.0.0.1:3001)，选择自定义服务，地址填写`http://127.0.0.1:3002/v1`，模型填写`ui-test-model`，测试密钥填写`local-ui-test-key`。

`tests/live-debug.mjs`用于人工授权后的真实接口检查，从标准输入读取配置，不把凭据写入文件。真实生成结果、题目语义和交互规则需要结合使用情境审阅；结构校验主要保证场景可渲染、计算可执行和引用有效。

## 公式输入组件

公式编辑使用[MathLive](https://mathlive.io/mathfield/guides/integration/)，数值代入使用[Compute Engine](https://mathlive.io/compute-engine/guides/evaluate/)。组件与字体从本机加载，版本及原始下载校验值见public/vendor/sources.json。计算入口保留代数与三角函数运算，使用独立变量作用域和计算时限。
