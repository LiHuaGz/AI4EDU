# 任意球示例演示指南

本指南用于教师与演示者准备。示例名称为“补时绝杀：一脚任意球的数学”，课堂设计为180分钟，上台可用8～10分钟展示关键链条。

## 1．演示前打开示例

在项目根目录启动本地服务：

```powershell
node src/server.mjs
```

打开[本地demo](http://127.0.0.1:3000)，在“连接AI”页面点击“用示例项目体验完整流程”，再点“进入示例项目”。页面标题应为“补时绝杀：一脚任意球的数学”。进入新项目会开始一份新的学习记录，已有记录可先导出。

示例题目、三级提示、公式输入、数值核对和Python实验台均从本机加载。Python首次运行需要初始化，演示前可先在第1题运行一次模板。已连接AI时，提示与反馈也可以针对学生当前的公式与代码实时生成。

## 2．8～10分钟演示顺序

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0～1分钟 | 展示第1题情境，展开“学习起点与挑战安排” | 补时阶段的任意球，训练中那一脚从横梁上方飞出。学生已能解二次函数与一元二次不等式，会回归直线；难度为“较难”，要跨越到线性化回归、窗口求解和概率决策。 |
| 1～2分钟 | 第1题拖动“出球速度v”和“起脚仰角θ”，输入v＝20.8、θ＝21.1 | 学生只凭已学知识用两个点估计，图中均方根误差约0.067米。这一题记录的是独立表现。 |
| 2～4分钟 | 第2题展开方法说明与Python模板，补全b、a两个表达式并运行 | 把y／x＝m－kx当作回归直线，已学公式直接可用；支架在这里最多。 |
| 4～5分钟 | 输入v＝21.56、θ＝20.30，点击“固定拟合参数，显示验证点” | 金色点现在才出现。拟合误差约0.045米，验证误差约0.074米，模型可信。 |
| 5～6分钟 | 第3题点击“载入拟合结果”，展开“查看计算结果与条件检查” | 过墙高度2.381米，球门线高度2.605米，高出横梁0.165米：习惯脚法从横梁上方飞出。第2题核对通过后，本题方法说明自动收起。 |

需要演示支架撤除时，在第2题填完整公式、数值和解释，再点击“核对数值”。随后进入第3题，方法说明默认收起，学生仍可重新展开。演示模拟学生作答时，可以明确说明这是一份演示记录。

## 3．最近发展区可以这样讲

“学生的已有能力是解二次不等式、求回归直线。这个项目要求他们把带误差的追踪数据转成直线再回归，用预留点检验，再把窗口宽度转成进球概率，最后同时调整两个变量。第1题先观察独立尝试；第2题通过线性化提示、统计量和代码模板提供支持；第3题撤去方法说明；最后一题改变条件，由学生独立迁移。”

最近发展区的依据是独立表现与在帮助下可达到的表现之间的差距，而章节先后只帮助确定可能适合学习的内容。参见[Vygotsky《Mind in Society》第86～87页](https://home.fau.edu/musgrove/web/vygotsky1978.pdf)。

本项目的3项相邻拓展为残差与回归模型的拟合效果、可线性化的非线性回归模型、正态分布的区间概率与经验规则。支架依表现调整、逐步撤除与责任转移参考[van de Pol等的综述](https://research.vu.nl/en/publications/scaffolding-in-teacher-student-interaction-a-decade-of-research/)。数值核对、方法说明、统计量、代码模板与三级提示分别留下记录；公式和解释需要结合这些记录评阅。

演示展示的是教学设计与证据收集方式。是否适合某个真实学生，应依据其实际尝试判断。

## 4．数学模型与参考数值

题目依次要求完成以下内容：

| 题目 | 需要完成的主要工作 |
| --- | --- |
| 第1题：建立轨迹方程，并用两个追踪点估计 | 写出轨迹方程，用P1、P8解出k、θ、v，读出均方根误差。 |
| 第2题：最小二乘估计并用预留点检验 | 线性化关系、回归公式、k、θ、v、两组均方根误差与检验结论。 |
| 第3题：判断习惯脚法的结果 | 人墙处与球门线处的高度、飞行时间、结果判断与可靠性。 |
| 第4题：求起脚仰角窗口 | 两个关于m的二次不等式、窗口上下限与宽度、时间条件检验。 |
| 第5题：计算进球概率 | 概率表达式、习惯瞄准与最优瞄准的概率、对90％要求的判断。 |
| 第6题：同时调整速度与仰角 | 窗口宽度模型、两个方案的概率、v*与θ₀*、方案比较。 |

### 4.1 轨迹与线性化

以罚球点为原点，忽略空气阻力与旋转：

$$
y=x\tan\theta-\frac{g\,x^{2}}{2v^{2}\cos^{2}\theta}=mx-kx^{2},\qquad m=\tan\theta,\quad k=\frac{g(1+m^{2})}{2v^{2}}
$$

两边除以$x$得到$z=y/x=m-kx$，这是一条截距为$m$、斜率为$-k$的直线。第1题用P1（2，0.72）、P8（16，2.85）两点：$k=0.01299$，$m=0.3860$，$\theta=21.1°$，$v=20.8$米每秒。

第2题对8个拟合点用最小二乘法：$\bar x=9$，$\bar z=0.26199$，$\sum(x_i-\bar x)^2=168$，$\sum(x_i-\bar x)(z_i-\bar z)=-2.01330$。得到$b=-0.011984$、$a=0.36985$，所以$k=0.011984$，$\theta=20.30°$，$v=21.56$米每秒。残差按$y$计算，拟合均方根误差0.045米，验证均方根误差0.074米。

追踪数据由$v=22$米每秒、$\theta=20°$的真实轨迹加上约0.05米的读数误差得到，估计值与之相差不大。

### 4.2 四个入门条件与窗口

进球须同时满足：①$y(9.15)\ge2.1$；②$y(20)\le2.44$；③$y(20)\ge0$；④$20/(v\cos\theta)\le1.2$。

固定$v$后，令$c=g/(2v^{2})$。条件①整理为$c\cdot9.15^{2}m^{2}-9.15m+(c\cdot9.15^{2}+2.1)\le0$，解集在两根之间，给出窗口下限；条件②整理为$c\cdot20^{2}m^{2}-20m+(c\cdot20^{2}+2.44)\ge0$，解集在两根之外，10°至45°内取较小根以下，给出窗口上限；条件④给出上限$\arccos(20/(1.2v))$。

$v=21.6$米每秒时，窗口为18.60°至19.76°，宽度1.16°，条件④在窗口内成立（上限处飞行时间0.984秒）。

### 4.3 起脚偏差与进球概率

实际仰角$\Theta\sim N(\theta_0,\sigma^{2})$，$\sigma=0.8°$：

$$
P(\theta_0)=\Phi\!\left(\frac{\theta_2-\theta_0}{\sigma}\right)-\Phi\!\left(\frac{\theta_1-\theta_0}{\sigma}\right)
$$

瞄准窗口中点19.18°时最大，$P=2\Phi(w/\sigma)-1=0.5308$，其中$w=0.579°$；瞄准习惯仰角20.30°时$P\approx0.23$。

### 4.4 同时调整速度与仰角

速度降低时，横梁条件的上限升高，时间条件的上限$\arccos(20/(1.2v))$降低，窗口宽度在两个上限相等处最大。数值搜索（步长0.01）得到：

| 量 | 数值 |
| --- | --- |
| 最优出球速度v* | 18.45米每秒（习惯速度21.56，降低约3.1） |
| 窗口 | 20.82°至25.40°，宽度4.58° |
| 瞄准仰角θ₀* | 23.11°（习惯仰角20.30°，抬高约2.8°） |
| 进球概率 | 0.9958 |
| 方案1：保持21.6米每秒 | 最大概率0.5308 |

方案1未达到90％，方案2达到。窗口宽度对速度很敏感：v＝18.2时概率约0.90，v＝18.0时约0.45，出球速度的稳定性是下一步训练的重点。

## 5．Python演示填空

第1题把两个`None`替换为：

```python
k = (z[0] - z[-1]) / (x[-1] - x[0])
m = z[0] + k * x[0]
```

第2题：

```python
b = Sxz / Sxx
a = z_bar - b * x_bar
```

第2题运行验证误差前，需要先在图形中输入v、θ并固定拟合参数。第3题的轨迹函数：

```python
return x * m - g * (1 + m**2) * x**2 / (2 * v**2)
```

第4题的横梁条件根：

```python
m_bar = roots(c * D**2, -D, c * D**2 + bar)[0]
```

第5题的概率与最优瞄准：

```python
return Phi((theta_high - aim) / sigma) - Phi((theta_low - aim) / sigma)
aim_best = (theta_low + theta_high) / 2
```

第6题补全`window(v)`中的横梁根，其余搜索代码已经给出：

```python
bar_roots = roots(c * D**2, -D, c * D**2 + bar)
```

Python使用[Pyodide的工作线程方式](https://pyodide.org/en/0.28.3/usage/webworker.html)，计算时页面仍可操作。停止按钮中止当前线程，后续运行会重新初始化。模板只提供计算结构，最终表达式、数值和判断仍填写在本题作答区。
